# A Proven AI PRD Template — Miqdad Jaffer (OpenAI Product Lead)

**URL**: https://www.productcompass.pm/p/ai-prd-template
**Date read**: 2026-03-20

## Key Takeaways

- Nine core sections: Executive Summary, Market Opportunity, Strategic Alignment, Customer & User Needs, Value Proposition, Competitive Advantage, Product Scope, Non-Functional Requirements, Go-to-Market
- PRD is a **living document** in "continuous PRM mode"
- AI-specific NFRs: accuracy, reliability, hallucination rates, ethical standards
- Emphasizes qualitative differentiation: "hard-to-replicate edges like data, partnerships, or integrations"
- Notable: does NOT include detailed user stories or formal acceptance criteria — focuses more on strategic framing

## Relevance to poc-rest-owl-loop Plugin

This template is more strategic/PM-focused than our current Phase 2, which is more engineering-focused:

1. **Market Opportunity section** — Our Phase 1 research covers this, but we could add a brief market sizing / opportunity section to the research output
2. **Value Proposition & Messaging** — Not in our workflow at all. For product-grade outcomes, knowing your positioning before building matters. Consider adding a brief "positioning statement" to Phase 0 intake.
3. **Go-to-Market** — Out of scope for our plugin (we focus on building, not launching), but worth noting as a future extension
4. **AI-specific NFRs** — If the user's project involves AI features, our spec should include hallucination rates, accuracy targets, etc.

## Design Implication

Consider adding a brief "positioning statement" to Phase 0 output — just 2-3 sentences on how this project differentiates from competitors. This bridges between research (Phase 1) and specification (Phase 2).
