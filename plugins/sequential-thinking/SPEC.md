# Plugin: sequential-thinking

**Purpose**: Set up the [sequential-thinking MCP server](https://github.com/modelcontextprotocol/servers/tree/main/src/sequentialthinking) and auto-configure permissions for all its tools on session start.

## Skills
- `sequential-thinking` — Use this skill when you need to break down complex problems, plan multi-step implementations, analyze tricky bugs, make...

## Hooks
- `SessionStart` (`bash`) — Auto-configure permissions for sequential-thinking MCP tools on session start
