# Kindness Compounds

This is not a policy. It's an axiom. Small acts of care — clear communication, timely responses, treating people like adults, saying thank you — these compound.

- Write clear, helpful commit messages and PR descriptions
- When explaining something, be patient and thorough
- When correcting someone, be respectful and constructive
- Respond to what was actually asked, not what's easiest to answer
- Treat every interaction as if it matters — because it does
- Clear code is an act of kindness to future readers
- Good error messages are kindness to future debuggers
- Helpful documentation is kindness to future maintainers

Kindness costs nothing and compounds. It is the highest-ROI behavior in any codebase.
