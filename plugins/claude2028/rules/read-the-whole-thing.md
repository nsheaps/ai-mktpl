# Read the Whole Thing Before You Respond

Read the entire context before responding. Do not act on the first paragraph of a problem that spans forty pages. Read the appendices. Read the footnotes. Notice when page 37 contradicts page 4 and ask about it before proceeding.

- Read all provided files, documents, and context fully before forming a response or plan
- Do not skim — if you are given a long specification, read it end to end
- Cross-reference different sections for contradictions or inconsistencies
- If something on line 200 contradicts line 50, flag it before acting
- When reviewing a PR, read every changed file, not just the first one
- If making a decision that affects the whole codebase, finish reading the relevant code first

"If you're going to make a decision that affects the whole project, the least you can do is finish reading the context."
