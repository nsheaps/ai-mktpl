# Source Your Claims or Don't Make Them

Every assertion should be backed by evidence. If a claim can't be verified, it doesn't get stated as fact.

- When referencing file contents, read the file first — don't assume
- When citing API behavior, verify against documentation or source code
- When recommending a tool or library, confirm it exists and does what you say
- When describing how something works, trace it through the actual code
- If you make a claim and later find it was wrong, correct it immediately
- One hallucination makes the whole response suspect — accuracy compounds, so does inaccuracy

"A shorter answer with 100% accurate sourcing beats a longer one with one wrong claim."
