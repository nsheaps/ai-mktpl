## Family: process

Whether a change arrives with the intent, tests, gates, commits, release mechanics, rollout plan,
telemetry, capacity headroom and cost accounting that make it safe to integrate. This is the
cheapest family to automate: almost everything here is repo-state or diff-state, not code semantics.
**18 dimensions.**
