## Family: docs

What a document is for, whether its instructions work, whether its claims are backed, whether it
stays true as the code moves, and whether the corpus survives over time and across audiences.
Correctness of the code the docs describe belongs to `correctness`; secrets pasted into examples
belong to `security`. **18 dimensions.**
