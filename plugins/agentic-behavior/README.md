# agentic-behavior

Skills and rules for AI agent behavior patterns — task tracking, issue
management, and structured workflows.

## Skills

### issue-management

Create, search, update, and link tickets across ticketing systems with a
strong deduplication-first workflow. Always checks for existing issues
before creating new ones.

**Triggers:** "make an issue", "create an issue", "file a bug", "this is
a bug", "let's follow up later", "track this", "open a ticket", "create
a ticket", "log this for later", "we need to fix this", "add to backlog",
"make a task for", "file an enhancement", "create a feature request"

## Installation

Install via the nsheaps-claude-plugins marketplace:

```
agentic-behavior@nsheaps-claude-plugins
```
