# Plugin: zai-glm

**Purpose**: Skills for using [z.ai](https://z.ai/) (formerly Zhipu AI) GLM models and configuring access from Claude Code environments.

## Skills
- `glm-models` — Use this skill when the user asks about GLM models, GLM-5, GLM-4.7, GLM-4.6, GLM-4.5, GLM-4V, ChatGLM, CogView,...
- `zai-setup` — Use this skill when the user asks about z.ai, Zhipu AI, setting up z.ai API access, getting a z.ai API key, configuring...
